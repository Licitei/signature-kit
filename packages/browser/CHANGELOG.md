## @signature-kit/browser@2.0.0-alpha.1 (alpha)

### Engine and browser packages

The engine provides the RPC contract, local services and WebAssembly bindings.
The browser package provides the worker, client and viewer.

# Changelog

## 2.0.0-alpha.0

- Add a versioned browser worker runtime for immutable document revisions and scoped A1 signing sessions.
- Add offline PDF inspection, worker rendering and a framework-free canvas viewer.

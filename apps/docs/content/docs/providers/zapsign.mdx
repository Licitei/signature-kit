---
title: ZapSign
description: "Envie um PDF para assinatura na ZapSign com token Bearer em Redacted e receba a URL de assinatura e falhas tipadas."
---

`@signature-kit/zapsign` envia o PDF para a ZapSign com a lista de signatários e devolve um `ZapSignDocument` com `id`, `state` e, quando disponível, a URL de assinatura do primeiro signatário. A assinatura acontece na ZapSign.

## Instalação

```package-install
@signature-kit/http @signature-kit/zapsign
```

## Quando usar

Use a ZapSign quando o produto precisa de um link de assinatura hospedado a partir de um único PDF. Se a aplicação deve gerar os bytes assinados, use a [assinatura A1 de PDF](/docs/signing/pdf).

<Callout type="warn" title="Credenciais em Redacted">
  O token entra como `Redacted.make(...)` e só é aberto na chamada HTTP. Não passe tokens para componentes React nem
  para logs.
</Callout>

## Solicitação mínima

```ts title="zapsign.ts"
import * as Alchemy from "alchemy"
import { ZapSignSignatureRequest, providers as zapSignProviders } from "@signature-kit/zapsign"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: Layer.merge(
      zapSignProviders({
        apiToken: Redacted.make(process.env.ZAPSIGN_API_TOKEN ?? ""),
        environment: "sandbox",
        locale: "pt-br",
      }),
      signatureHttpClientLive,
    ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* ZapSignSignatureRequest("contrato-de-servico", {
      title: "Contrato de serviço",
      message: "Revise e assine este documento.",
      documents: [{ fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 }],
      recipients: [{ name: "Ana Silva", email: "ana@example.com", routingOrder: 1 }],
      send: true,
    })
  }),
) {}
```

## Detalhes da integração

- `environment` aceita `"production"`, `"sandbox"` (padrão) ou `"brazil"` (`https://br.api.zapsign.com.br/api/v1`). `baseUrl` substitui os três.
- A autenticação usa o `apiToken` no cabeçalho `Authorization: Bearer`.
- Um PDF por solicitação. Outro MIME ou mais de um documento falham antes da chamada HTTP.
- `locale` aceita `"pt-br"`, `"es"` ou `"en"`. `authMode` define o método de autenticação do signatário na ZapSign (por exemplo `"assinaturaTela"`, `"tokenEmail"` ou `"certificadoDigital"`).
- `send: false` ou `disableSignerEmails: true` desligam os e-mails da ZapSign aos signatários.

## Outras operações

`getZapSignSignatureRequest`, `listZapSignSignatureRequests`, `cancelZapSignSignatureRequest`, `deleteZapSignSignatureRequest` e `downloadZapSignSignedDocument` recebem as mesmas opções de `providers(...)` e exigem `SignatureHttpClient`. O download falha com `signature-kit.UNSUPPORTED_OPERATION` enquanto não houver arquivo assinado.

## Aguarde um estado final

`waitForZapSignSignatureRequest(options, id, pollInterval)` consulta o documento na hora e repete a cada `pollInterval` enquanto o estado for `draft` ou `sent`. O retorno traz o estado final (`completed`, `cancelled`, `deleted`, `declined` ou `expired`); confira `state` antes de baixar o documento. O intervalo precisa ser positivo e finito. Falhas de consulta não são repetidas automaticamente, e interromper o Effect cancela a consulta em andamento. O prazo máximo fica com a aplicação:

```ts title="wait.ts"
import { waitForZapSignSignatureRequest } from "@signature-kit/zapsign"
import type { ZapSignProviderOptions } from "@signature-kit/zapsign"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Duration, Effect } from "effect"

declare const options: ZapSignProviderOptions
declare const requestId: string

const program = waitForZapSignSignatureRequest(options, requestId, Duration.seconds(2)).pipe(
  Effect.timeout(Duration.minutes(5)),
  Effect.provide(signatureHttpClientLive),
)
```

## Erros

Entrada inválida, falhas HTTP e respostas em formato inesperado falham como `SignatureKitError`, com `provider`, `operation` e o `status` HTTP quando disponíveis.

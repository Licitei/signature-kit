---
title: Assinafy
description: "Crie solicitações de assinatura na Assinafy com API key ou token de acesso, por conta, e falhas tipadas como SignatureKitError."
---

`@signature-kit/assinafy` envia o PDF, cadastra os signatários e cria o assignment na conta configurada da Assinafy. O resultado é um `AssinafySignatureRequestAttributes` com `id`, `state` e as URLs devolvidas. A assinatura acontece na Assinafy.

## Instalação

```package-install
@signature-kit/http @signature-kit/assinafy
```

## Quando usar

Use a Assinafy quando a organização por conta e o acompanhamento do assignment ficam na Assinafy. Se a aplicação precisa controlar os bytes assinados e o posicionamento, use a [assinatura A1 de PDF](/docs/signing/pdf).

<Callout type="warn" title="Credenciais em Redacted">
  A chave entra como `Redacted.make(...)` e só é aberta na chamada HTTP. Não passe credenciais para componentes React
  nem para logs.
</Callout>

## Solicitação mínima

```ts title="assinafy.ts"
import * as Alchemy from "alchemy"
import { AssinafySignatureRequest, providers as assinafyProviders } from "@signature-kit/assinafy"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: Layer.merge(
      assinafyProviders({
        apiKey: Redacted.make(process.env.ASSINAFY_API_KEY ?? ""),
        accountId: process.env.ASSINAFY_ACCOUNT_ID ?? "",
        environment: "sandbox",
      }),
      signatureHttpClientLive,
    ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* AssinafySignatureRequest("contrato-de-servico", {
      title: "Contrato de serviço",
      message: "Revise e assine este documento.",
      documents: [{ fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 }],
      recipients: [{ name: "Ana Silva", email: "ana@example.com", routingOrder: 1 }],
      send: true,
    })
  }),
) {}
```

## Detalhes da integração

- As credenciais são `accountId` mais `apiKey` (cabeçalho `X-Api-Key`) ou `accessToken` (cabeçalho `Authorization: Bearer`).
- `environment` aceita `"production"` ou `"sandbox"` (padrão). `baseUrl` substitui os dois.
- Um PDF por solicitação (`mimeType: "application/pdf"`).
- Os signatários não têm `role`; `routingOrder` vira a etapa do assignment.
- Com `send: false`, o assignment é criado sem notificação por e-mail.

## Outras operações

`getAssinafySignatureRequest`, `listAssinafySignatureRequests`, `deleteAssinafySignatureRequest` e `downloadAssinafySignedDocument` recebem as mesmas opções de `providers(...)` e exigem `SignatureHttpClient`. Não há função de cancelamento. O download falha com `signature-kit.UNSUPPORTED_OPERATION` enquanto não houver documento assinado.

## Aguarde um estado final

`waitForAssinafySignatureRequest(options, id, pollInterval)` consulta a solicitação na hora e repete a cada `pollInterval` enquanto o estado for `draft` ou `sent`. O retorno traz o estado final (`completed`, `cancelled`, `deleted`, `declined` ou `expired`); confira `state` antes de baixar o documento. O intervalo precisa ser positivo e finito. Falhas de consulta não são repetidas automaticamente, e interromper o Effect cancela a consulta em andamento. O prazo máximo fica com a aplicação:

```ts title="wait.ts"
import { waitForAssinafySignatureRequest } from "@signature-kit/assinafy"
import type { AssinafyProviderOptions } from "@signature-kit/assinafy"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Duration, Effect } from "effect"

declare const options: AssinafyProviderOptions
declare const requestId: string

const program = waitForAssinafySignatureRequest(options, requestId, Duration.seconds(2)).pipe(
  Effect.timeout(Duration.minutes(5)),
  Effect.provide(signatureHttpClientLive),
)
```

## Erros

Entrada inválida, falhas HTTP e respostas em formato inesperado falham como `SignatureKitError`, com `provider`, `operation` e o `status` HTTP quando disponíveis.

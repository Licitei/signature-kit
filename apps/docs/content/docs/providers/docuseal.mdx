---
title: DocuSeal
description: "Crie submissões de PDF na DocuSeal com a chave no cabeçalho X-Auth-Token, em Redacted, e falhas tipadas como SignatureKitError."
---

`@signature-kit/docuseal` cria uma submissão de PDF na DocuSeal e devolve um `DocuSealSubmissionAttributes` com `id`, `state` e o link de assinatura. A DocuSeal tem código aberto e pode ser hospedada por você; o pacote fala com qualquer instância pelo `baseUrl`. A assinatura acontece na DocuSeal.

## Instalação

```package-install
@signature-kit/http @signature-kit/docuseal
```

## Quando usar

Use a DocuSeal quando uma plataforma de assinatura de código aberto deve hospedar a submissão e coletar as assinaturas. Se a aplicação deve gerar os bytes assinados, use a [assinatura A1 de PDF](/docs/signing/pdf).

<Callout type="warn" title="Credenciais em Redacted">
  A chave entra como `Redacted.make(...)` e só é aberta na chamada HTTP. Não passe chaves para componentes React nem
  para logs.
</Callout>

## Solicitação mínima

```ts title="docuseal.ts"
import * as Alchemy from "alchemy"
import { DocuSealSignatureRequest, providers as docuSealProviders } from "@signature-kit/docuseal"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: Layer.merge(
      docuSealProviders({
        apiKey: Redacted.make(process.env.DOCUSEAL_API_KEY ?? ""),
        baseUrl: "https://api.docuseal.com",
        sendSms: false,
        submittersOrder: "preserved",
      }),
      signatureHttpClientLive,
    ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* DocuSealSignatureRequest("contrato-de-servico", {
      title: "Contrato de serviço",
      message: "Revise e assine este documento.",
      documents: [{ fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 }],
      recipients: [{ name: "Ana Silva", email: "ana@example.com", role: "signer" }],
      send: true,
    })
  }),
) {}
```

## Detalhes da integração

- A submissão é criada em `POST /submissions/pdf`, e a chave vai no cabeçalho `X-Auth-Token`.
- `baseUrl` tem como padrão `https://api.docuseal.com`; aponte para a sua instância se você hospeda a DocuSeal.
- Aceita um ou mais PDFs. `subject` define o assunto do e-mail.
- `role` é texto livre e vira o papel do signatário na DocuSeal.
- `send: false` cria a submissão sem enviar e-mails. `sendSms` liga o envio por SMS.
- `submittersOrder` aceita `"preserved"` (padrão, na ordem de `recipients`) ou `"random"`.

## Outras operações

`getDocuSealSignatureRequest`, `listDocuSealSignatureRequests`, `deleteDocuSealSignatureRequest` e `downloadDocuSealSignedDocument` recebem as mesmas opções de `providers(...)` e exigem `SignatureHttpClient`. Não há função de cancelamento. O download falha com `signature-kit.UNSUPPORTED_OPERATION` enquanto não houver documento assinado.

## Aguarde um estado final

`waitForDocuSealSignatureRequest(options, id, pollInterval)` consulta a submissão na hora e repete a cada `pollInterval` enquanto o estado for `draft` ou `sent`. O retorno traz o estado final (`completed`, `cancelled`, `deleted`, `declined` ou `expired`); confira `state` antes de baixar o documento. O intervalo precisa ser positivo e finito. Falhas de consulta não são repetidas automaticamente, e interromper o Effect cancela a consulta em andamento. O prazo máximo fica com a aplicação:

```ts title="wait.ts"
import { waitForDocuSealSignatureRequest } from "@signature-kit/docuseal"
import type { DocuSealProviderOptions } from "@signature-kit/docuseal"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Duration, Effect } from "effect"

declare const options: DocuSealProviderOptions
declare const requestId: string

const program = waitForDocuSealSignatureRequest(options, requestId, Duration.seconds(2)).pipe(
  Effect.timeout(Duration.minutes(5)),
  Effect.provide(signatureHttpClientLive),
)
```

## Erros

Entrada inválida, falhas HTTP e respostas em formato inesperado falham como `SignatureKitError`, com `provider`, `operation` e o `status` HTTP quando disponíveis.

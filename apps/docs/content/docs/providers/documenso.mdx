title: Documenso
description: "Crie envelopes na API v2 da Documenso com envio de PDFs em multipart, chave em Redacted e falhas tipadas como SignatureKitError."
---

`@signature-kit/documenso` cria um envelope na API v2 da Documenso, envia os PDFs como multipart e distribui o envelope aos destinatários quando `send` não é `false`. O resultado é um `DocumensoEnvelope` com `id`, `state` e as URLs devolvidas. A Documenso tem código aberto e pode ser hospedada por você. A assinatura acontece na Documenso.

## Instalação

```package-install
@signature-kit/http @signature-kit/documenso
```

## Quando usar

Use a Documenso quando o envelope, a ordem dos destinatários e as ações de cada um ficam na Documenso. Se a aplicação deve gerar os bytes PDF/PAdES assinados, use a [assinatura A1 de PDF](/docs/signing/pdf).

<Callout type="warn" title="Credenciais em Redacted">
  A chave entra como `Redacted.make(...)` e só é aberta na chamada HTTP. Não passe chaves para componentes React nem
  para logs.
</Callout>

## Solicitação mínima

```ts title="documenso.ts"
import * as Alchemy from "alchemy"
import { DocumensoSignatureRequest, providers as documensoProviders } from "@signature-kit/documenso"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Effect, Layer, Redacted } from "effect"

export default class Contracts extends Alchemy.Stack<Contracts>()(
  "Contracts",
  {
    providers: Layer.merge(
      documensoProviders({
        apiKey: Redacted.make(process.env.DOCUMENSO_API_KEY ?? ""),
        baseUrl: "https://app.documenso.com/api/v2",
      }),
      signatureHttpClientLive,
    ),
    state: Alchemy.inMemoryState(),
  },
  Effect.gen(function* () {
    return yield* DocumensoSignatureRequest("contrato-de-servico", {
      title: "Contrato de serviço",
      message: "Revise e assine este documento.",
      documents: [{ fileName: "contract.pdf", mimeType: "application/pdf", contentBase64: pdfBase64 }],
      recipients: [{ name: "Ana Silva", email: "ana@example.com", role: "signer" }],
      send: true,
    })
  }),
) {}
```

## Detalhes da integração

- O envelope é criado em `POST /envelope/create` e distribuído em `POST /envelope/distribute`.
- `baseUrl` tem como padrão `https://app.documenso.com/api/v2`; aponte para a sua instância se você hospeda a Documenso.
- A chave vai no cabeçalho `Authorization` como está (`authorizationScheme: "raw"`, padrão) ou com prefixo `Bearer` (`"bearer"`).
- Aceita um ou mais PDFs. `subject` define o assunto do e-mail.
- `role` aceita `"signer"` ou `"approver"`; `routingOrder` vira a ordem de assinatura do envelope.
- Com `send: false`, o envelope é criado e fica em `draft`, sem distribuição.

## Outras operações

`getDocumensoSignatureRequest`, `listDocumensoSignatureRequests`, `cancelDocumensoSignatureRequest`, `deleteDocumensoSignatureRequest` e `downloadDocumensoSignedDocument` recebem as mesmas opções de `providers(...)` e exigem `SignatureHttpClient`. O download falha com `signature-kit.UNSUPPORTED_OPERATION` enquanto o envelope não estiver concluído.

## Aguarde um estado final

`waitForDocumensoSignatureRequest(options, id, pollInterval)` consulta o envelope na hora e repete a cada `pollInterval` enquanto o estado for `draft` ou `sent`. O retorno traz o estado final (`completed`, `cancelled`, `deleted`, `declined` ou `expired`); confira `state` antes de baixar o documento. O intervalo precisa ser positivo e finito. Falhas de consulta não são repetidas automaticamente, e interromper o Effect cancela a consulta em andamento. O prazo máximo fica com a aplicação:

```ts title="wait.ts"
import { waitForDocumensoSignatureRequest } from "@signature-kit/documenso"
import type { DocumensoProviderOptions } from "@signature-kit/documenso"
import { signatureHttpClientLive } from "@signature-kit/http"
import { Duration, Effect } from "effect"

declare const options: DocumensoProviderOptions
declare const requestId: string

const program = waitForDocumensoSignatureRequest(options, requestId, Duration.seconds(2)).pipe(
  Effect.timeout(Duration.minutes(5)),
  Effect.provide(signatureHttpClientLive),
)
```

## Erros

Entrada inválida, falhas HTTP e respostas em formato inesperado falham como `SignatureKitError`, com `provider`, `operation` e o `status` HTTP quando disponíveis.

---
title: Solicitações remotas de assinatura
description: "Provedores remotos conduzem a assinatura na plataforma deles; eles não são backends locais do serviço Signatures."
---

Clicksign, Assinafy, ZapSign, DocuSeal e Documenso são provedores remotos. As APIs deles criam documentos, signatários, envelopes, links e notificações na própria plataforma. Eles não alteram os seus bytes de PDF ou XML pelo serviço `Signatures`.

## Quando usar cada um

- Use o serviço `Signatures` local quando o SignatureKit assina os bytes do documento.
- Use as funções de solicitação do provedor quando a plataforma dele conduz a coleta de assinaturas.
- Mantenha os tokens do provedor em `Redacted`. Erros HTTP nunca serializam segredos.

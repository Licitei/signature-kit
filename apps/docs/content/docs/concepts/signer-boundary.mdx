---
title: Fronteira do signer
description: "O signer define de onde vem a chave; os pacotes de formato definem como o documento muda."
---

O `SignerAdapter` é a fronteira do poder de assinar. Ele lê a identidade do certificado, expõe o certificado, importa a chave de assinatura, assina bytes e verifica bytes. Ele não sabe se quem chama está montando XML-DSig, PAdES, CMS ou uma prévia de UI.

Com essa separação, o A1 é um backend entre outros. Um backend A3 (token, smartcard ou HSM) pode implementar o mesmo contrato sem mudar o código de PDF ou XML.

## Divisão de responsabilidades

- O signer responde **de onde vem a chave**.
- O pacote de formato responde **como o documento muda**.
- A borda da aplicação fornece a layer concreta do signer.

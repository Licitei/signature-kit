---
title: Fluxo de PDF no navegador
description: "Leia um PDF no navegador, posicione o campo de assinatura e assine com um certificado A1 usando os helpers de @signature-kit/pdf."
---

Os helpers de navegador ligam um `<input type="file">` ao estado do builder de PDF. Os bytes ficam dentro do `Effect`, o template de posicionamento é validado por Schema e o campo selecionado é assinado com a layer A1 que você fornecer.

## Passos

<Steps>
  <Step title="Leia o arquivo">`readPdfBlobBytes(file)` converte um `Blob` do navegador em `Uint8Array`, com falhas no canal de erro tipado.</Step>
  <Step title="Monte o estado de posicionamento">`createPdfSignatureBuilderStateFromBytes(...)` lê as dimensões das páginas, cria o template e, se você pedir, posiciona um campo de rascunho. Essa etapa usa o motor `PdfCore`.</Step>
  <Step title="Renderize sua UI">Crie um `PdfSignatureBuilderStore` uma vez e conecte o store à sua UI com o mecanismo de inscrição que o seu framework já usa (React, Vue ou Svelte).</Step>
  <Step title="Assine os bytes">`signPdfSignatureField(...)` gera a aparência do campo selecionado no PDF e delega a criptografia ao serviço `Signatures`.</Step>
</Steps>

```ts title="browser-a1-flow.ts"
import { a1SignaturesLayer } from "@signature-kit/a1/signer"
import {
  createPdfSignatureBuilderStateFromBytes,
  readPdfBlobBytes,
  signPdfSignatureField,
} from "@signature-kit/pdf/workflow"
import { createPdfSignatureBuilderStore } from "@signature-kit/pdf/builder-store"
import { pdfCoreBrowserLayer } from "@signature-kit/pdf-core/browser"
import { Effect, Redacted } from "effect"

const pdf = await Effect.runPromise(readPdfBlobBytes(file))
const state = await Effect.runPromise(
  createPdfSignatureBuilderStateFromBytes({
    id: "contract-a1",
    name: file.name,
    documentId: "contract",
    documentName: file.name,
    pdf,
    role: { id: "signer", label: "Signatário A1", required: true },
    draft: { id: "sig", type: "signature", roleId: "signer", width: 156, height: 42 },
    autoPlacement: { page: "last", slot: "bottom-right", margin: 24 },
  }).pipe(Effect.provide(pdfCoreBrowserLayer)),
)

const store = createPdfSignatureBuilderStore(state)

const signedPdf = await Effect.runPromise(
  signPdfSignatureField({
    pdf,
    template: store.getSnapshot().template,
    fieldId: "sig",
    reason: "Assinado localmente com A1",
    signatureLength: 16384,
  }).pipe(
    Effect.provide(a1SignaturesLayer({ pfx, password: Redacted.make(password) })),
    Effect.provide(pdfCoreBrowserLayer),
  ),
)
```

## Assinatura em lote

Use `signPdfSignatureBatch(items, callbacks)` para assinar vários PDFs com o mesmo certificado A1. Os documentos são assinados em sequência, e cada falha volta como um resultado (`ok: false`) daquele documento, sem interromper o lote.

## Preparação em Web Worker

`PdfWorker` prepara os documentos e gera a prévia do carimbo em um Web Worker, com transporte pelo RPC nativo do Effect. A layer de navegador encerra o worker quando o escopo fecha, e interromper o Effect cancela a sessão. Os callbacks de progresso rodam na página, e os bytes originais continuam com quem chamou. Certificado e senha não passam pelo worker: forneça a layer A1 onde a assinatura é executada.

```ts
import type { PdfSigningBatchPreparationInput } from "@signature-kit/pdf/config"
import { PdfWorker } from "@signature-kit/pdf/worker"
import { pdfWorkerBrowserLayer } from "@signature-kit/pdf/worker-browser"
import { Effect } from "effect"

const prepare = (input: PdfSigningBatchPreparationInput) =>
  Effect.gen(function* () {
    const worker = yield* PdfWorker
    return yield* worker.prepare(input)
  }).pipe(Effect.provide(pdfWorkerBrowserLayer()))
```

---
title: Primeiro uso
description: "Carregue um certificado A1, leia a identidade do titular e assine bytes, XML e PDF em um programa Effect."
---

Você vai montar um programa Effect que carrega o certificado A1, lê a identidade do titular, assina e verifica bytes e, depois, assina um XML e um PDF com a mesma layer.

<Steps>
  <Step title="Instale os pacotes">
    Adicione o runtime, o signer A1 e o `effect`, que fornece `Effect` e `Redacted`.

    ```bash
    bun add @signature-kit/signatures @signature-kit/a1 effect
    ```
  </Step>

  <Step title="Carregue o A1, inspecione, assine e verifique">
    O `a1SignaturesLayer` recebe os bytes do `.pfx` e a senha em `Redacted` e fornece o serviço `Signatures`. O `signatures.inspect()` retorna um `SignerIdentity`, cujo campo `document` traz o CPF ou o CNPJ do titular quando o certificado tem esse dado. Em seguida, `signatures.sign` e `signatures.verify` usam a mesma layer.

    O algoritmo é `"rsa-sha256"` ou `"rsa-sha512"`. O catálogo também aceita `"rsa-sha1"` por compatibilidade com sistemas legados, mas evite-o em assinaturas novas.

    <Callout type="error" title="Os bytes do .pfx, não o caminho">
      `pfx` é um `Uint8Array` com o conteúdo binário do `.pfx`/`.p12`, e não uma string com o caminho do arquivo. Mantenha esses bytes e a senha fora de logs e do controle de versão.
    </Callout>

    ```ts title="quickstart.ts"
    import { a1SignaturesLayer } from "@signature-kit/a1/signer"
    import { signatures } from "@signature-kit/signatures"
    import { Effect, Redacted } from "effect"

    const layer = a1SignaturesLayer({
      pfx,                                          // Uint8Array com os bytes do .pfx/.p12
      password: Redacted.make(process.env.A1_PASSWORD ?? ""),
    })

    export const program = Effect.gen(function* () {
      // identity.document traz o CPF ou o CNPJ do titular
      const identity = yield* signatures.inspect()

      const content = new TextEncoder().encode("content to sign")
      const artifact = yield* signatures.sign({
        content,
        algorithm: "rsa-sha256",
      })

      const result = yield* signatures.verify({
        content,
        signature: artifact.signature,
        algorithm: artifact.algorithm,
      })

      return { identity, artifact, result }
    }).pipe(Effect.provide(layer))
    ```

    Uma assinatura inválida não é erro: o `verify` retorna `result.valid` igual a `false`. Quando a verificação não consegue rodar, a falha chega como `SignatureKitError` no canal de erro, sem exceção lançada.
  </Step>

  <Step title="Execute o programa">
    Execute o `Effect` com `Effect.runPromise` na borda da aplicação ou componha-o em outro programa Effect.

    ```ts title="run.ts"
    import { Effect } from "effect"

    const { result } = await Effect.runPromise(program)
    console.log(result.valid) // true se a assinatura for válida
    ```
  </Step>

  <Step title="Assine XML e PDF">
    Os dois formatos consomem a mesma layer de assinatura. O XML também precisa do `xmlRuntimeLayer`, e o PDF precisa da layer do motor `PdfCore` (`pdfCoreFileLayer` no Node e no Bun, `pdfCoreBrowserLayer` no navegador). `verifyXml` e `verifyPdf` leem a chave pública do próprio documento e não exigem a layer de assinatura.

    ```package-install
    @signature-kit/xml @signature-kit/pdf @signature-kit/pdf-core @effect/platform-node
    ```

    ```ts title="documents.ts"
    import { signXml } from "@signature-kit/xml/sign"
    import { xmlRuntimeLayer } from "@signature-kit/xml/runtime"
    import { signPdf } from "@signature-kit/pdf/sign"
    import { pdfCoreFileLayer } from "@signature-kit/pdf-core/file"
    import * as NodeServices from "@effect/platform-node/NodeServices"
    import { a1SignaturesLayer } from "@signature-kit/a1/signer"
    import { Effect, Layer, Redacted } from "effect"

    const layer = a1SignaturesLayer({
      pfx,                                          // Uint8Array com os bytes do .pfx/.p12
      password: Redacted.make(process.env.A1_PASSWORD ?? ""),
    })
    const pdfCoreLayer = pdfCoreFileLayer.pipe(Layer.provide(NodeServices.layer))

    const signedXml = signXml({ xml, referenceId: "nfe-1" })
      .pipe(Effect.provide(layer), Effect.provide(xmlRuntimeLayer))

    const signedPdf = signPdf({ pdf, policy: "pades-icp-brasil" })
      .pipe(Effect.provide(layer), Effect.provide(pdfCoreLayer))
    ```
  </Step>
</Steps>

## Erros que você pode encontrar

<Callout type="warn" title="Senha do certificado incorreta">
  Se a senha do `.pfx` estiver errada, a layer de assinatura falha com [`signature-kit.WRONG_PASSWORD`](/docs/signing/errors#error-catalog) no canal de erro, sem lançar exceção. Confira o segredo antes de continuar.
</Callout>

- [`signature-kit.SIGN_FAILED`](/docs/signing/errors#error-catalog): não foi possível assinar o conteúdo.
- [`signature-kit.VERIFY_FAILED`](/docs/signing/errors#error-catalog): não foi possível verificar a assinatura.

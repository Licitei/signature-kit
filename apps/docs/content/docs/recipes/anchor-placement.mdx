---
title: Posicionamento por âncora
description: "Encontre marcadores de texto, CPF, CNPJ ou link no PDF e transforme-os em retângulos de assinatura."
---

Use `findPdfTextAnchors` quando o próprio documento já indica onde vai a assinatura. A função procura o texto nas caixas de texto extraídas pelo SignatureKit e devolve os retângulos prontos, sem `pdfjs-dist` nem cálculo manual de matrizes de transformação.

```ts title="anchor-placement.ts"
import { findPdfTextAnchors } from "@signature-kit/pdf/anchors"
import { type PdfSignaturePage } from "@signature-kit/pdf/config"
import { prepareAndSignPdf } from "@signature-kit/pdf/workflow"
import { pdfCoreBrowserLayer } from "@signature-kit/pdf-core/browser"
import { Effect, Layer } from "effect"

const pages: Array<PdfSignaturePage> = template.documents[0]?.pages ?? []

const stampRects = await Effect.runPromise(
  findPdfTextAnchors({
    pdf,
    pages,
    matchers: [
      { text: "assinatura:" },
      { digits: "12345678901" },      // CPF/CNPJ: compara só os dígitos
    ],
    stampSize: { width: 180, height: 54 },
    placement: "below",
    offset: 6,
  }).pipe(Effect.provide(pdfCoreBrowserLayer)),
)

const signedPdf = await Effect.runPromise(
  prepareAndSignPdf({
    pdf,
    pages,
    stampRects,
    badge: {
      header: { text: "ASSINADO DIGITALMENTE" },
      rows: [[{ label: "Signatário", value: "Maria Souza" }]],
      footer: [{ text: "ICP-Brasil" }],
    },
    rubric: { initials: "MS" },
    signing: { policy: "pades-icp-brasil", name: "Maria Souza" },
  }).pipe(Effect.provide(Layer.merge(layer, pdfCoreBrowserLayer))),
)
```

`digits` remove tudo o que não é dígito do matcher e do texto do PDF, então `123.456.789-01` e `12345678901` são equivalentes. Os retângulos retornados nunca ultrapassam as bordas da página.

## Gerar com takumi-pdf e depois assinar

Se você gera PDFs com [`takumi-pdf`](https://www.npmjs.com/package/takumi-pdf), instale o componente `pdf-signature-anchor` pelo [registry](/docs/recipes/react-components) e coloque marcadores invisíveis no JSX. Carregue o takumi só no cliente, para que a pré-renderização estática nunca execute WASM.

```tsx title="takumi-declaration.tsx"
import { render } from "takumi-pdf"
import {
  PdfSignatureAnchor,
  PdfSignatureLinkAnchor,
} from "@/components/signature-kit/pdf-signature-anchor"
import { findPdfTextAnchors } from "@signature-kit/pdf/anchors"
import { prepareAndSignPdf } from "@signature-kit/pdf/workflow"
import { pdfCoreBrowserLayer } from "@signature-kit/pdf-core/browser"
import type { SignatureKitError, Signatures } from "@signature-kit/signatures"
import { Effect, Layer } from "effect"

export async function generateAndSign(
  fontBytes: Uint8Array,
  signerLayer: Layer.Layer<Signatures, SignatureKitError>,
) {
  const pdf = await render(
    <main className="flex flex-col gap-2 p-12 text-[11px]">
      <h1 className="text-base font-bold">Declaração de Habilitação</h1>
      <p>Declaro, sob as penas da lei, que atendo às condições de habilitação exigidas no edital.</p>
      <div className="mt-6 flex flex-col items-center gap-1">
        <PdfSignatureAnchor token="{{signature}}" />
        <PdfSignatureLinkAnchor href="https://signature.invalid/anchor" />
      </div>
    </main>,
    { size: "a4", fonts: [{ name: "Liberation", data: fontBytes }] },
  )

  return Effect.runPromise(
    Effect.gen(function* () {
      const stampRects = yield* findPdfTextAnchors({
        pdf,
        matchers: [{ text: "{{signature}}" }, { link: "https://signature.invalid/anchor" }],
        stampSize: { width: 180, height: 54 },
        placement: "below",
        offset: 6,
      })
      return yield* prepareAndSignPdf({
        pdf,
        stampRects,
        badge: {
          header: { text: "ASSINADO DIGITALMENTE" },
          rows: [[{ label: "Signatário", value: "Maria Souza" }]],
          footer: [{ text: "ICP-Brasil" }],
        },
        rubric: { initials: "MS" },
        signing: { policy: "pades-icp-brasil", name: "Maria Souza" },
      })
    }).pipe(Effect.provide(Layer.merge(signerLayer, pdfCoreBrowserLayer))),
  )
}
```

O takumi-pdf só emite anotações de link `http(s)` e descarta sem aviso esquemas de URI personalizados, por isso as âncoras de link precisam usar uma URI `https://`. O valor padrão, `https://signature.invalid/anchor`, usa o domínio reservado `.invalid` e não abre nada se alguém clicar.

<Callout type="info">
  A extração de texto roda no motor WASM do `@signature-kit/pdf-core`: forneça `pdfCoreBrowserLayer` no navegador ou `pdfCoreFileLayer` no Node e no Bun. Se você já extrai o texto por conta própria, passe `pages` e `textBoxes` com matchers de texto ou de dígitos; nesse caso `findPdfTextAnchors` não exige nenhum serviço.
</Callout>

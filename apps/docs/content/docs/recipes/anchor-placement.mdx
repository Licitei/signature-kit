---
title: Posicionamento por âncora
description: "Encontre âncoras de texto como assinatura, CPF ou CNPJ e transforme-as em retângulos de assinatura PDF."
---

Use `findPdfTextAnchors` quando o documento de negócio já nomeia a área de assinatura. Ele substitui scans com `pdfjs-dist` e matemática manual de transform por um matcher do pacote sobre text boxes do SignatureKit.

```ts title="anchor-placement.ts"
import { findPdfTextAnchors } from "@signature-kit/pdf/anchors"
import { type PdfSignaturePage } from "@signature-kit/pdf/config"
import { prepareAndSignPdf } from "@signature-kit/pdf/workflow"
import { pdfCoreBrowserLayer } from "@signature-kit/pdf-core/browser"
import { Effect, Layer } from "effect"

const pages: Array<PdfSignaturePage> = template.documents[0]?.pages ?? []

const stampRects = await Effect.runPromise(
  findPdfTextAnchors({
    pdf,
    pages,
    matchers: [
      { text: "assinatura:" },
      { digits: "12345678901" },      // CPF/CNPJ: compara só números
    ],
    stampSize: { width: 180, height: 54 },
    placement: "below",
    offset: 6,
  }).pipe(Effect.provide(pdfCoreBrowserLayer)),
)

const signedPdf = await Effect.runPromise(
  prepareAndSignPdf({
    pdf,
    pages,
    stampRects,
    badge: {
      header: { text: "ASSINADO DIGITALMENTE" },
      rows: [[{ label: "Signatário", value: "Maria Souza" }]],
      footer: [{ text: "ICP-Brasil" }],
    },
    rubric: { initials: "MS" },
    signing: { policy: "pades-icp-brasil", name: "Maria Souza" },
  }).pipe(Effect.provide(Layer.merge(layer, pdfCoreBrowserLayer))),
)
```

`digits` normaliza o matcher e o texto do PDF para strings só com números, então `123.456.789-01` e `12345678901` casam. Os retângulos retornados ficam limitados aos limites da página.

## Gerar com takumi-pdf e depois assinar

Quando você gera PDFs com [`takumi-pdf`](https://www.npmjs.com/package/takumi-pdf) em vez de `@react-pdf/renderer`, instale `pdf-signature-anchor` pelo registry e coloque marcadores invisíveis no seu JSX. Carregue o takumi só no cliente, para que a pré-renderização estática nunca execute WASM.

```tsx title="takumi-declaration.tsx"
import { render } from "takumi-pdf"
import {
  PdfSignatureAnchor,
  PdfSignatureLinkAnchor,
} from "@/components/signature-kit/pdf-signature-anchor"
import { findPdfTextAnchors } from "@signature-kit/pdf/anchors"
import { prepareAndSignPdf } from "@signature-kit/pdf/workflow"
import { pdfCoreBrowserLayer } from "@signature-kit/pdf-core/browser"
import { Effect, Layer } from "effect"

export async function generateAndSign(fontBytes: Uint8Array, signerLayer: Layer.Layer<unknown>) {
  const pdf = await render(
    <main className="flex flex-col gap-2 p-12 text-[11px]">
      <h1 className="text-base font-bold">Declaração de Habilitação</h1>
      <p>Declaro, sob as penas da lei, que atendo às condições de habilitação exigidas no edital.</p>
      <div className="mt-6 flex flex-col items-center gap-1">
        <PdfSignatureAnchor token="{{signature}}" />
        <PdfSignatureLinkAnchor href="https://signature.invalid/anchor" />
      </div>
    </main>,
    { size: "a4", fonts: [{ name: "Liberation", data: fontBytes }] },
  )

  return Effect.runPromise(
    Effect.gen(function* () {
      const stampRects = yield* findPdfTextAnchors({
        pdf,
        matchers: [{ text: "{{signature}}" }, { link: "https://signature.invalid/anchor" }],
        stampSize: { width: 180, height: 54 },
        placement: "below",
        offset: 6,
      })
      return yield* prepareAndSignPdf({
        pdf,
        stampRects,
        badge: {
          header: { text: "ASSINADO DIGITALMENTE" },
          rows: [[{ label: "Signatário", value: "Maria Souza" }]],
          footer: [{ text: "ICP-Brasil" }],
        },
        rubric: { initials: "MS" },
        signing: { policy: "pades-icp-brasil", name: "Maria Souza" },
      })
    }).pipe(Effect.provide(Layer.merge(signerLayer, pdfCoreBrowserLayer))),
  )
}
```


O takumi-pdf só emite anotações de link `http(s)` e descarta em silêncio esquemas de URI personalizados, então as âncoras de link precisam usar uma URI `https://`. O padrão `https://signature.invalid/anchor` usa o TLD reservado `.invalid`, então nunca resolve se alguém clicar.

<Callout type="info">
  A extração de texto roda no núcleo WASM próprio (`@signature-kit/pdf-core`): forneça `pdfCoreBrowserLayer` no navegador ou `pdfCoreFileLayer` no Node e no Bun. Para usar sua própria extração, passe `pages` e `textBoxes` e mantenha o posicionamento em `findPdfTextAnchors`; essa chamada não precisa de serviço.
</Callout>

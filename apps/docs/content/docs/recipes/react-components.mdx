`@signature-kit/react` publica só hooks. Para começar com uma UI pronta, use o registry shadcn: os arquivos são copiados para a sua aplicação, e armazenamento, textos, estilo, fetch/tRPC e regras de produto ficam sob o seu controle.

```bash title="Instalar um componente"
npx shadcn@latest add https://signaturekit.dev/r/signature-dialog.json
```

## Itens do registry

| Item | Comando | Uso |
| --- | --- | --- |
| `signature-certificate-form` | `npx shadcn@latest add https://signaturekit.dev/r/signature-certificate-form.json` | Confirmação de senha, com persistência pelos callbacks `getSavedPassword` e `onSavePassword`. |
| `certificate-upload-form` | `npx shadcn@latest add https://signaturekit.dev/r/certificate-upload-form.json` | Seleciona o `.pfx`/`.p12`, lê o certificado no navegador com `useA1Certificate`, mostra os metadados e chama o seu callback de upload. |
| `signature-pdf-viewer` | `npx shadcn@latest add https://signaturekit.dev/r/signature-pdf-viewer.json` | Prévia com `react-pdf`, destaque das âncoras de texto e posicionamento manual por clique. |
| `signature-dialog` | `npx shadcn@latest add https://signaturekit.dev/r/signature-dialog.json` | Assinatura A1 direta com `useA1Signer`, nova tentativa com a senha salva, progresso e prévia ou download do PDF assinado. |
| `signing-progress-list` | `npx shadcn@latest add https://signaturekit.dev/r/signing-progress-list.json` | Status de cada documento para uma tela de assinatura personalizada. |
| `pdf-signature-anchor` | `npx shadcn@latest add https://signaturekit.dev/r/pdf-signature-anchor.json` | Marcadores invisíveis para `takumi-pdf` (texto e link) usados com `findPdfTextAnchors`. |

## Diálogo de assinatura direta

```tsx title="sign-button.tsx"
import { SignatureDialog } from "@/components/signature-kit/signature-dialog"

export function SignButton({ pfx }: { pfx: Uint8Array }) {
  return (
    <SignatureDialog
      pfx={pfx}
      anchorTokens={["{{signature}}"]}
      getSavedPassword={() => null}
      onWrongPassword={() => {
        // Apague aqui a senha que a sua aplicação guardou.
      }}
      buildDocuments={async () => [
        {
          id: "contract",
          name: "contract.pdf",
          pdf: await fetch("/contract.pdf").then(async (response) =>
            new Uint8Array(await response.arrayBuffer()),
          ),
          anchors: {
            matchers: [{ text: "{{signature}}" }],
            stampSize: { width: 180, height: 54 },
          },
        },
      ]}
      signing={{ policy: "pades-icp-brasil", reason: "Assinado com SignatureKit" }}
      stamp={{
        badge: {
          header: { text: "ASSINADO DIGITALMENTE" },
          rows: [[{ label: "Signatário", value: "Usuário atual" }]],
          footer: [{ text: "ICP-Brasil" }, { text: "SignatureKit" }],
        },
        rubric: { initials: "UA" },
      }}
      onSigned={(rows) => {
        // Envie, visualize ou baixe rows[n].signedPdf.
      }}
    />
  )
}
```

## Posicionamento por âncora

Se você gera PDFs com `takumi-pdf`, use âncoras invisíveis. As variantes de texto e de link correspondem aos matchers `text` e `link` de `findPdfTextAnchors`.

```tsx title="contract.tsx"
import { render } from "takumi-pdf"
import {
  PdfSignatureAnchor,
  PdfSignatureLinkAnchor,
} from "@/components/signature-kit/pdf-signature-anchor"

export async function buildContractPdf(fontBytes: Uint8Array) {
  return render(
    <main className="p-12 text-[11px]">
      <p>Signatário</p>
      <div className="mt-4 flex flex-col items-center gap-1">
        <PdfSignatureAnchor token="{{signature}}" />
        <PdfSignatureLinkAnchor href="https://signature.invalid/anchor" />
      </div>
    </main>,
    { size: "a4", fonts: [{ name: "Liberation", data: fontBytes }] },
  )
}
```

O fluxo completo (gerar o PDF, chamar `findPdfTextAnchors` e depois `prepareAndSignPdf`) está em [Posicionamento por âncora](/docs/recipes/anchor-placement).

Use o `signature-pdf-viewer` quando alguém precisar conferir as âncoras ou posicionar a assinatura manualmente.

### `react-pdf` em frameworks com SSR

O `react-pdf` usa APIs do navegador e não pode rodar na renderização do servidor. Carregue-o atrás da fronteira de hidratação descrita em [Pré-visualização com react-pdf](/docs/recipes/react-pdf-preview).

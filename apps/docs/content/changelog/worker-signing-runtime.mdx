## Runtime de assinatura em worker publicado

Publicamos `@signature-kit/signatures/session`, que o `@signature-kit/react` 0.1.2 importa para assinar documentos com A1 em um worker Domain RPC. Sem essa entrada, os bundlers não conseguiam resolver o worker do pacote React.

No A1, a etapa de assinatura com WebCrypto passa a ser não interrompível. O CMS monta o atributo signing-certificate-v2 diretamente com asn1js. Todos os pacotes passam para o Effect 4.1.0, para que as aplicações carreguem um único runtime Effect.

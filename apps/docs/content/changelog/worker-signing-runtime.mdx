## Publicar o runtime de assinatura em worker

Publicamos `@signature-kit/signatures/session`, que o `@signature-kit/react` 0.1.2 importa para assinar documentos com A1 em um worker Domain RPC. Sem ele, os bundlers não conseguem resolver a entrada do worker do react.

A assinatura com A1 torna a etapa de assinatura WebCrypto não interrompível. O CMS monta o atributo signing-certificate-v2 direto com asn1js. Todos os pacotes passam para o Effect 4.1.0, para que as aplicações carreguem um único runtime Effect.

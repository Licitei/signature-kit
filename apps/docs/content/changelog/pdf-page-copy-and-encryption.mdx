## Cópia de páginas de PDF e erros de documento criptografado

Use `mergePdfs(pdfs, { signedSources: "flatten" })` para criar uma prévia sem assinatura a partir de PDFs assinados. Ele remove os widgets de assinatura e os metadados de formulário, mas mantém os carimbos desenhados no conteúdo da página. Por padrão, o merge continua rejeitando fontes assinadas.

Use `extractPdfPages(pdf, pageIndexes)` para copiar uma seleção não vazia de páginas (índices a partir de zero) para um novo PDF.

Preparação, carimbo, busca de âncoras de texto e cópia de páginas agora retornam `pdf.ENCRYPTED_PDF` para entradas criptografadas, com mensagens em inglês e português do Brasil.

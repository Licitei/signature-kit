## Cliente com Promises para apps sem Effect

`loadPdfCoreNode()` (`@signature-kit/pdf-core/node`) e `loadPdfCoreBrowser()` (`@signature-kit/pdf-core/promise`) carregam o módulo WebAssembly e retornam as operações do `PdfCore` como Promises que rejeitam com o `PdfCoreError`, para que um app use o motor sem instalar nem importar `effect`. `createPdfCoreClient(module)` monta o mesmo cliente a partir de um módulo compilado, e `pdfCoreBrowserModule` expõe o carregador de módulo do navegador que fica por trás do `pdfCoreBrowserLayer`.

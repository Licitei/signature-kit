## Ler PDFs com senha de abertura vazia

O PdfCore consegue inspecionar, extrair texto e tabelas, descrever, renderizar e mesclar PDFs com Standard Security que abrem com senha de usuário vazia. Ele suporta RC4 nas revisões 2–4, AES-128 na revisão 4 e AES-256 nas revisões 5–6. Merge e edições completas geram um PDF sem criptografia. O modo de edição automático reescreve entradas criptografadas, inclusive ao preparar a primeira assinatura. Uma edição incremental explícita ou uma entrada que exige senha de usuário não vazia falha com `pdfCore.ENCRYPTED_PDF`.

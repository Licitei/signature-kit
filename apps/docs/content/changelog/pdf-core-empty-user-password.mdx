## Leitura de PDFs com senha de abertura vazia

O PdfCore agora inspeciona, extrai texto e tabelas, descreve, renderiza e mescla PDFs protegidos com Standard Security que abrem com senha de usuário vazia. São suportados RC4 nas revisões 2 a 4, AES-128 na revisão 4 e AES-256 nas revisões 5 e 6. O merge e as edições completas geram um PDF sem criptografia. No modo de edição automático, entradas criptografadas são reescritas, inclusive ao preparar a primeira assinatura. Uma edição incremental explícita, ou uma entrada que exige senha de usuário não vazia, falha com `pdfCore.ENCRYPTED_PDF`.

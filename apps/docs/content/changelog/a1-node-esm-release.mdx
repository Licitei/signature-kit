## A1 carrega no ESM nativo do Node

O pacote publicado agora traz os imports relativos com o caminho completo, como já estavam no código-fonte. Com isso, `@signature-kit/a1/signer` carrega no ESM nativo do Node em vez de falhar com `ERR_MODULE_NOT_FOUND`.

Esta versão também remove o serviço `A1Signer` e o `a1SignerLayer`, que não eram usados. Use `a1SignaturesLayer` ou `loadA1SignerAdapter`.

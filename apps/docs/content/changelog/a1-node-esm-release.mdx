## Publicar o A1 com imports resolvíveis pelo Node

Publicamos os imports relativos totalmente especificados que já estavam no código-fonte, para que `@signature-kit/a1/signer` carregue no ESM nativo do Node em vez de falhar com `ERR_MODULE_NOT_FOUND`.

Esta versão também remove o serviço `A1Signer` e o `a1SignerLayer`, que não eram usados; use `a1SignaturesLayer` ou `loadA1SignerAdapter`.
